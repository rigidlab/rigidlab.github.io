BViz - A Basic Visualization library
## Intro
Quickly plot and interact with data in the following domains:

- Financial Data (Open,High,Low,Close,Volume,Datetime)
- Robotics Data (x,y,theta,timestamp)

Type of plots based on (dynamical system visualization):

- Time series
- Phase space
- Vector Field
